# 客服页面改版与验证记录

更新日期：2026-09-08。本文记录本轮对真机截图反馈的修正，取代首次改版中「顶部显示关联信息」和「后台跳转详情列表」的设计。

## 当前实现

- 按最后确认的要求，小程序顶部不显示商品、订单或售后关联栏。底部可关闭的待发送卡片保留；关闭提示不会解除后台关联，也不会自动发送聊天消息。
- 欢迎头像独立定位，凸出短问候气泡；开场白和蓝色常见问题链接继续读取后台配置。
- 发送后的商品、订单、售后采用紧凑白色卡片，去掉旧的类型标题与底部分隔查看栏。订单号、售后号单行省略，状态、金额与商品信息分别排版；商品卡有明确的查看入口。
- 输入框与加号的单行高度统一为 64rpx。原生 textarea 不再叠加竖直内边距，多行输入仍可扩展。
- 加号保留 45 度旋转；展开仅有相册、拍摄、订单、商品。商品直接打开订单、浏览、收藏、购物车标签弹层，没有旧的来源图标二级面板。没有语音、表情或输入栏独立商品按钮。
- 相册、拍摄、商品沿用首次改版复制的指定 SVG；订单沿用个人页的全部订单图标。已确认旧 chat-add/back/cart/favorite/order 资源和旧面板没有残留引用。

## 后台工作台

右侧固定顺序为「当前咨询」「相关订单」「相关商品」「相关售后」，每个分区始终存在，没有内容时显示空状态。取消表格边框和层层卡框，改为商品图、标题、编号、金额及状态的简洁列表。

关联行为：商品入口绑定商品；订单入口绑定订单和订单内商品；售后入口绑定售后、订单及售后涉及的商品。相关售后同时根据本次关联订单查询，因此从订单进入也能看到已经存在的售后申请。未发送对象卡片时，客服仍可看到这些关联。

聊天卡片、右侧列表都在客服页面打开详情抽屉。订单、售后、商品可在抽屉内逐层查看并返回，页面地址保持 `/customer-service`。商品补充只读详情，含主图、分类、状态、规格价格、库存、卖点与隔离渲染的商品图文。订单和售后采用现有详情格式的分区、标签和值，没有编辑表格。

详情接口沿用会话读取权限，并校验资源与该会话当前或历史咨询的关联。普通客服只能读取自己接待会话的关联资源，不能通过修改 ID 读取其他用户或无关订单、商品、售后；商品响应不暴露成本价格。售后凭证也沿用会话范围校验。

修复历史订单图片的空字符串回退，避免空的 display_image / sku_image 挡住 main_image。无新增数据库迁移。后端与管理端需要配套发布。

## 视觉验收

- 参考：用户提供的京东客服截图及本轮小程序、工作台反馈截图。
- 小程序：微信开发者工具 Stable 2.02.2608040，基础库 2.32.3，iPhone 15 Pro Max 模拟器，81% 显示缩放。检查欢迎头像、已发送卡片、输入栏、加号展开、商品弹层及关闭。读取已有会话展示数据，没有向实际客服发送验收消息。
- 后台：真实 Vue 页面连接本地 Spring Boot 测试配置与独立 H2 内存库，使用虚构用户、订单和售后。1440 × 900 与 1280 × 800 下检查工作台；较窄尺寸页面宽度和 scrollWidth 同为 1280，无横向溢出。三类消息卡片宽度均为 360px，四个右侧分区都可见。
- 交互：打开商品详情、订单详情、相关售后；从订单进入商品或售后后返回上一层；关闭抽屉后保留原会话。图片、规格价格、申请原因及订单字段均实际加载。
- 对照：将原生手机区域与参考归一化为 393 × 852；后台将修改前后右侧区域统一宽度对比。最终图中已修正高问候气泡、旧卡片底栏、编号换行、无售后分区和多层边框问题。
