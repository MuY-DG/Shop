# Shop 首页装修后端与后台实施计划

日期：2026-07-14

设计依据：`docs/superpowers/specs/2026-07-14-shop-home-decoration-backend-admin-design.md`

## 任务 1：迁移与权限骨架

1. 先增加 schema 测试，断言装修表、菜单父子关系、权限与超级管理员授权存在。
2. 新增 Flyway V19：创建装修表和联系配置；新增菜单与权限；迁移轮播和素材库菜单；回填历史角色父菜单。
3. 运行 schema 测试，验证 H2/MySQL 兼容语法。

## 任务 2：首页分类后端

1. 先写控制器集成测试，覆盖新增、查询、修改、删除、状态过滤、重复分类和素材引用。
2. 增加 DTO、控制器和服务。
3. 接入公开图片验证、素材使用关系和内容变更事件。
4. 运行分类相关测试。

## 任务 3：首页热门/推荐商品后端

1. 先写集成测试，覆盖两个分区隔离、商品选择、覆盖图、上下架过滤、重复商品和删除。
2. 使用单一 `home_product_item` 服务，通过固定分区控制器暴露两个管理接口。
3. 增加独立的分类/商品选项接口，按装修权限授权。
4. 扩展商品永久删除约束与缓存失效。
5. 运行商品编排与商品回收相关测试。

## 任务 4：首页聚合与 Redis

1. 先写缓存单元测试，覆盖命中、未命中写入、Redis 故障回源、内容事件清理和 TTL 上限。
2. 增加首页查询服务、聚合 DTO、公开控制器与缓存服务。
3. 轮播、装修、分类和商品变更在事务提交后清理首页缓存。
4. 将 `/app/home` 加入公开安全规则，保留 `/app/home/banners`。
5. 运行聚合接口与缓存测试。

## 任务 5：联系我后端

1. 先写管理/公开接口测试，覆盖权限、格式校验、持久化与公开读取。
2. 增加联系配置服务、管理控制器、公开控制器与独立 Redis 缓存。
3. 将 `/app/contact` 加入公开安全规则。
4. 运行联系配置测试。

## 任务 6：后台 API 与可测试状态逻辑

1. 先增加纯 TypeScript 测试，覆盖分类扁平化、装修表单 payload、商品价格展示和电话规范化。
2. 扩展 `Api.Content` 类型和 `admin/src/api/content.ts`。
3. 运行 `tsx --test`。

## 任务 7：后台页面

1. 实现首页分类页面并复用 `AssetPicker`。
2. 实现热门/推荐共享编排组件和两个薄页面入口。
3. 实现联系设置页面。
4. 通过动态菜单组件路径加载新页面。
5. 运行 `pnpm typecheck`、目标 lint 和生产构建。

## 任务 8：回归与自审

1. 运行后端目标测试，再运行完整 `./mvnw test`。
2. 运行后台状态测试、`pnpm typecheck` 与 `pnpm build`。
3. 检查 `git diff --check`、迁移兼容性、权限父子关系和未提交用户改动。
4. 进行一次代码自审，修复发现的问题后重复验证。
