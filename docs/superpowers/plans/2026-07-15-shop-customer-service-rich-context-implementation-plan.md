# Shop 在线客服按次咨询与富消息实施计划

日期：2026-07-15

设计依据：`docs/superpowers/specs/2026-07-15-shop-customer-service-rich-context-design.md`

## 工作区边界

本阶段建立在未提交的第一版客服实现以及现有订单、售后、昵称改动之上：

- 不回滚、不覆盖、不格式化无关改动。
- 使用 V24 增量迁移，不修改可能已被本地数据库执行的 V23。
- 优先扩展独立客服文件；商品详情、订单控制器、存储枚举等共享文件只做窄修改。
- 不默认给客服角色授予退款、关闭订单或发货等资金/履约写权限。

## Slice 1：迁移与回归测试

1. 先扩展迁移测试，覆盖咨询轮次、商品关联、菜单父子关系和客服查看权限。
2. 新增 V24：咨询轮次与当前对象字段、消息资源字段、统一咨询资源表、菜单和角色授权。
3. 更新固定 Flyway 版本断言。

## Slice 2：后端咨询语义和卡片消息

1. 扩展控制器测试：商品入口默认上下文、订单入口所有权、活动轮次新增对象、关闭后新轮次不继承旧关联。
2. 扩展 DTO 和会话映射，增加当前上下文、当前轮次订单/商品以及结构化消息内容。
3. 实现用户和当前客服发送订单/商品卡片，候选商品查询和实时事件。
4. 保留文字幂等与认领、转接、关闭的并发边界。

## Slice 3：私有图片消息

1. 新增客服图片上传策略和存储测试。
2. 实现 App/Admin 图片上传发送接口及私有读取接口。
3. 校验用户线程所有权、当前负责人和附件上下文，禁止跨会话读取。
4. 消息仅保存可信资产 ID，响应按消息返回尺寸和下载端点所需信息。

## Slice 4：管理后台

1. 扩展客服类型/API：上下文、商品、订单、图片上传与 Blob 下载。
2. 工作台顶部显示当前咨询对象，右侧显示本次咨询相关商品/订单。
3. 消息流渲染图片、商品卡片、订单卡片；增加发送图片、商品、订单操作。
4. 管理并释放图片 Object URL，保持实时刷新和轮询行为。

## Slice 5：小程序

1. 商品详情增加“联系客服”并携带商品；订单详情携带订单。
2. 客服页解析入口上下文并调用统一 open API。
3. 渲染当前咨询对象和富消息，支持选择/上传图片、发送自己的订单和当前商品。
4. 私有图片通过带 Token 的 `wx.downloadFile` 获取临时路径，保留鉴权恢复。

## Slice 6：交易菜单与 RBAC

1. 在线客服移动到交易管理并更新路由测试。
2. 客服角色获得交易、订单、售后菜单以及 `order:read`、`aftersale:read`。
3. 订单读接口增加 `order:read`，关闭接口增加 `order:close`，补充授权测试。

## Slice 7：完整验证

1. 后端目标测试后运行 `./mvnw test`。
2. 后台运行新增文件 lint、`pnpm typecheck` 和 `pnpm build`。
3. 小程序运行 `pnpm test`、`pnpm typecheck` 和 `pnpm test:typecheck`。
4. 运行 `git diff --check`，复核对象所有权、图片私有读取、旧轮次隔离和现有脏改动。
5. 输出真实微信开发者工具需要验证的商品入口、订单入口、双方图片和断线恢复场景。
