# COS 图片直传与数据万象迁移

## 目标链路

```text
管理后台 / 小程序
        │ 1. 申请一次性上传会话
        ▼
业务 API ── 返回仅允许一个对象键、一个 MIME 和一个文件大小的 POST Policy
        │
        │ 2. 文件直接上传到 private/direct-upload/... 临时对象
        ▼
腾讯云 COS
        │
        │ 3. 业务 API 仅发起 HEAD 与数据万象云上处理，不读取图片正文
        ▼
WebP 正图 / 缩略图 ── 4. 写入 storage_asset 后删除临时对象
```

业务服务器不再接收直传图片正文，也不再调用 Tinify。旧 Multipart
接口只保留给 SVG 和滚动发布期间的兼容客户端；支付证书、私钥等非图片
私密文件仍使用原有业务接口。

## 输出策略

| 场景 | 持久化输出 | 尺寸与质量 | 访问策略 |
| --- | --- | --- | --- |
| 素材库图片 | WebP | 最长边 2560，质量 85 | 公有读，`max-age=31536000, immutable` |
| 用户头像 | WebP | 最长边 1024，质量 85 | 公有读，长期缓存 |
| 售后凭证 | WebP | 最长边 4096，质量 90 | 私有读，签名访问 |
| 客服聊天正图 | WebP | 最长边 1920，质量 82 | 私有读，签名访问 |
| 客服聊天缩略图 | WebP | 最长边 720，质量 76 | 私有读，列表优先加载 |
| 素材库视频 | 原编码 | COS 内部服务端复制 | 公有读，长期缓存 |
| SVG | 原格式 | 保留后端安全解析 | 继续使用旧 Multipart 接口 |

聊天发送方在上传完成前显示本地临时图片；接收方优先下载 720px
缩略图。小程序将缩略图保存到本地，缓存最多 80 项、保留 7 天，预览时
再请求 1920px 正图。

完成接口为数据万象同步处理预留 180 秒客户端超时。若 COS/数据万象返回
临时处理错误，服务端对同一会话最多处理三次并执行 5 秒、10 秒退避；
管理后台和小程序会使用同一个 `uploadId` 重试完成请求，不会再次上传
图片正文。

如果客户端到 COS 的 POST 失败或被用户取消，客户端会使用独立的 5 秒
请求调用对应上传会话的 `DELETE` 接口。后端只会将仍处于 `INITIATED`
的所属会话原子标记为失败并立即释放活跃名额，再清理可能已经落盘的临时
对象；已经进入 `PROCESSING` 或 `COMPLETED` 的会话不会被取消或删除。
取消通知本身失败时保留原始上传错误，定时清理和 COS 生命周期规则继续
兜底。

本方案不使用 CDN。AVIF 在没有 CDN 自动内容协商时需要额外保存一份
文件、扩展所有业务 DTO，并由每个客户端判断兼容性；它还会增加聊天
完成接口的处理时间。因此当前统一使用兼容性更稳定的 WebP，不在上传
关键链路生成 AVIF。COS 存储、源站公网下行和数据万象基础图片处理仍会
按腾讯云规则计费。

当前存储桶的客户端上传 POST、公开素材/视频/头像 URL，以及客服和售后等
私有对象的短期签名 URL，统一使用对象存储配置中的 COS 客户端域名。该地址
必须是合法的 HTTPS 根域名，不能包含凭据、端口、路径或参数；可以使用 COS
默认域名，也可以使用已经绑定到当前存储桶的自定义默认源站。自定义
域名上传仍由同一份 POST Policy 约束，私有下载则由 SDK 针对自定义 Host
重新签名。保存自定义域名时，后端会通过 `GetBucketDomain` 验证它属于当前
存储桶且状态为 `ENABLED`、类型为 `REST`，并保存绑定域名、地域和存储桶的
校验指纹。升级前已有但没有校验指纹的自定义域名会显示为未配置，必须在
管理后台重新保存并通过验证；COS 默认域名不需要该指纹。历史上属于其他
存储桶或地域的私有对象仍使用其各自的默认 COS
源站，避免错误套用当前桶的 CNAME。如果生产库中的商品正文、订单快照或旧
素材已经保存过其他域名，这些存量字符串不会被代码盲目替换；应按真实旧
域名和存储桶单独迁移。

`GetBucketDomain` 只验证 COS **控制面**在保存时报告的绑定关系：域名精确匹配、
状态为 `ENABLED` 且类型为 `REST`。它不会上传对象，也不能替代对 DNS/CNAME、
HTTPS 证书、浏览器 CORS、微信合法域名、POST Policy 和公网链路的验证。因此
生产切换前仍必须使用配置中的自定义域名做一次真实文件 `POST` 冒烟，确认浏览器
预检（如有）和 `POST` 均成功、完成接口能落库，且返回的公开 URL 或私有签名 URL
可以实际读取；冒烟对象应使用一次性键并在验收后删除。

## 腾讯云控制台准备

### 1. 数据万象

确认当前 COS 存储桶已绑定数据万象，并可以执行云上图片处理和 WebP
转换。腾讯云在首次使用图片处理时可自动开通并绑定，但生产发布前应在
控制台明确检查，避免首个真实上传承担开通失败。

参考：

- [图片基础压缩（WebP）](https://cloud.tencent.com/document/product/460/60524)
- [缩放参数](https://cloud.tencent.com/document/product/460/36540)
- [去除元信息](https://cloud.tencent.com/document/product/460/36547)

### 2. CAM 权限

存储桶应保持“私有读写”，且 bucket policy 不得向匿名用户开放
`private/`。应用会再为每个暂存、聊天和售后对象显式设置 `private` ACL，
公共素材和头像的最终输出才显式设置 `public-read`。

后台保存的 COS 凭证至少需要在当前桶的对应对象前缀上具备：

- `cos:PostObject`：客户端使用后端签发的受限表单上传临时对象。
- `cos:GetObject`：HEAD 校验、COS 内部复制的源对象读取和私有签名读取。
- `cos:PutObject`：数据万象持久化、视频服务端复制和元数据更新。
- `cos:PutObjectACL`：将公共输出设为 `public-read`，私有输出设为 `private`。
- `cos:DeleteObject`：删除临时对象、替换后的文件和过期资产。
- `cos:GetBucketDomain`：保存自定义客户端域名时，确认该域名已在当前桶中
  启用为 `REST` 默认源站；使用 COS 默认域名时不调用此接口。

不要把 SecretKey 下发给客户端。客户端拿到的 Policy 同时锁定对象键、
Content-Type、精确文件长度、私有 ACL、禁止覆盖和 15 分钟有效期。
服务端还默认限制每个登录主体最多 10 个活跃会话；小程序用户每小时最多
签发 60 个，管理员每小时最多 600 个。这三个技术安全上限由
`application.yaml` 的 `shop.storage.direct-upload` 管理，不进入生产环境文件；
调整时必须保留有界上限并经过发布验证。

### 3. 管理后台 CORS

在 `安全管理 -> 跨域访问 CORS 设置` 中增加一条规则：

```text
Origin:       管理后台的每个真实 Origin，例如 https://admin.example.com
Methods:      POST, GET, HEAD
Allow-Headers: *
Expose-Headers: ETag, Content-Length, Location, x-cos-request-id
Max-Age:      600
Vary: Origin: 开启
```

不要为了省事把生产 Origin 配成 `*`。管理后台使用独立 XHR 获取上传进度，
不会向 COS 发送业务 Authorization 或 Cookie。浏览器可能因上传进度监听先
发送 `OPTIONS` 预检；保存规则后应在开发者工具中同时确认预检和实际
`POST` 都通过，COS 控制台会按上述允许方法响应预检。

参考：

- [Web 端直传实践](https://cloud.tencent.com/document/product/436/9067)
- [设置跨域访问](https://cloud.tencent.com/document/product/436/13318)
- [开启自定义源站域名](https://cloud.tencent.com/document/product/436/36638)
- [自定义域名上传下载对象](https://cloud.tencent.com/document/product/436/78322)

### 4. 微信小程序合法域名

在微信公众平台 `开发 -> 开发设置` 中配置：

```text
uploadFile 合法域名:
  对象存储配置中的 COS 客户端域名
  COS 默认源站域名（旧版本兼容和回滚期间保留）
  业务 API 域名（仅用于 SVG/旧版本兼容）

downloadFile 合法域名:
  对象存储配置中的 COS 客户端域名
  历史对象或回滚可能使用的 COS 默认源站域名
```

域名不带路径。当前存储桶的直传、公开读取和私有签名下载使用同一个配置
域名。自定义源站必须在 COS 中绑定为“默认源站”，直接 CNAME 到存储桶默认
域名，不需要也不会开启 CDN。管理后台和小程序从后端签发的上传会话动态
取得该 HTTPS 根域名，并拒绝包含凭据、端口、路径、查询参数或非法主机名的
上传地址。以后更换自定义域名时，仍必须先在微信公众平台增加对应合法域名并
发布兼容客户端，再切换后台对象存储配置。

参考：[小程序直传实践](https://cloud.tencent.com/document/product/436/34929)。

### 5. 临时对象兜底生命周期

应用会清理已完成、失败和过期的上传会话。仍建议在 COS 增加一条生命周期
规则，将前缀 `private/direct-upload/` 下最后修改时间超过 1 天的对象删除。
这只清理客户端直传的临时源文件，不要把规则扩大到 `public/` 或其他
`private/` 前缀。

**生产发布硬门禁：发布前必须在真实桶确认版本控制从未启用或当前不是
Enabled，并实际验证同一对象键第二次 POST 会被
`x-cos-forbid-overwrite=true` 拒绝。** 腾讯云明确说明，开启版本控制时该
字段无效；普通删除还只会产生删除标记，旧版暂存原图可能继续计费并保留
元信息。

如果现有桶已经启用过版本控制，不应直接按默认方案发布。需要先决定是否
使用一个未启用版本控制的独立暂存桶；若仍使用原桶，则必须接受同一 15
分钟凭证可重放覆盖的风险，并让生命周期规则永久清理
`private/direct-upload/` 的当前版本、非当前版本和过期删除标记。完成这些
验收前，直传功能不得进入生产流量。

## 发布顺序

1. 备份数据库，在真实桶完成数据万象、CAM、CORS 和生命周期检查。
2. 微信公众平台先把计划使用的自定义源站加入 `uploadFile` 和 `downloadFile` 合法域名，
   并暂时保留默认 COS 域名用于旧版本和回滚。
3. 先发布能动态接受后端签发的合法 HTTPS 根域名的管理后台、小程序。
4. 再部署包含 `V73__cos_direct_upload_sessions.sql`、
   `V75__verify_cos_custom_domain.sql` 及自定义源站上传支持的后端；若后台原先
   配置的是自定义域名，迁移后立即重新保存一次以完成 COS 控制面验证。
5. 用测试管理员上传 JPG、PNG、WebP、GIF 和视频，确认浏览器文件正文直接
   POST 到配置的自定义源站。
6. 真机验证头像、售后和买卖双方聊天，确认上传、公开读取和新生成的私有
   签名 URL 均使用配置域名。
7. 观察业务服务器流量、完成接口耗时、数据万象错误率和临时对象数量。
8. 确认所有客户端已升级后，再评估是否彻底下线 SVG 之外的旧图片 Multipart
   路径，以及是否从微信白名单移除默认 COS 域名。

滚动发布期间，客户端只有在后端明确返回
`STORAGE_DIRECT_UPLOAD_UNAVAILABLE (800009)`，或连接到尚无新路由的旧节点
（404/405/501）时才回退；尺寸、类型、网络和 COS 故障不会触发第二次
业务服务器上传。新客户端的正常路径不会调用这些兼容 Multipart 路由；
确认旧版客户端退出生产流量后，应再下线 SVG 之外的 legacy raster 路由，
才能从服务端入口层面彻底禁止普通图片走业务带宽。
