## 2026-08：Flyway generation 2 与三环境收敛

- 将数据库重建为七个领域基线：身份/RBAC（V1）、商品/内容/存储（V2）、
  交易/订单（V3）、支付/退款/售后（V4）、履约/微信（V5）、
  运营/财务/客服/合规（V6）与引用/引导数据（V7）。
- 应用环境统一为 `local`、`server`、`test`；txcloud 和 shop 共用服务器配置，
  每个目标只保留一份被 Git 忽略的五项启动秘密清单。
- 微信、支付、COS、服务动态和业务运行开关由 Admin 写入加密数据库；
  YAML 只保留连接启动秘密以及随版本评审的技术/安全边界。
- 重组 CI、配置和部署脚本；仓库不再接管 Docker/1Panel 安装或 1Panel 密码轮换。

## 2026-08：生产就绪业务基线

- 支持商品/数量级售后、部分与累计退款、仅退款、退货退款、商家验收/拒收、
  退货超时关闭与按数量幂等回补库存。
- 微信支付与退款回调使用不可猜测路由 token 精确绑定业务记录和数据库配置；
  支持退款恢复、微信交易账单日对账与差异审计。
- 支持拆分包裹、部分发货、微信发货可靠投递、物流轨迹、电子面单，
  以及 2001「购物（实体物流）服务动态」的顺序外呼、主动对账和审计。
- 完成商家资质、版本化法律文档、食品披露/上架门禁、账号自助注销、
  客户停用/恢复、不可变注销记录与 Admin 权限/审计链路。
- 小程序主包与支付/订单/购物车/商品详情体验完成收口；Admin 生产构建可重复，
  自动导入生成物纳入版本库并由 CI 校验。
