## 2026-08：生产就绪与微信深度集成（V81–V105）

- 微信物流：签收状态回传（V81）、电子面单（V83）、物流轨迹（V84）、发货可靠投递（V87）。
- 商品评价图片（V82）；下单支付截止与超时关单（V85）；按售后商品数量幂等回补库存（V86）。
- 商家资质、法律文档版本、食品披露与上架门禁（V88/V89）；账号注销与个人信息权利（V90）；
  管理员自助注册（V91）。
- 售后 V2：商品/数量级申请与审批、部分/累计退款、仅退款、退货退款、商家验收/拒收与
  退货超时关闭（V92），兼容历史整单 V1 工单。
- 微信交易账单下载、完整性校验、与本地成功支付/退款的日对账、差异处理与受控导出（V93）。
- 微信 2001「购物（实体物流）服务动态」：可靠状态投递、顺序外呼、主动对账、失败回调审计
  （V94–V96），Admin 运维页提供两阶段 Capture/Worker 开关、CAS 与追加审计（V95）。
- 财务对账 Admin 运行控制：数据库覆盖、分阶段启用、CAS、追加审计、即时停用（V97）。
- 账号注销改为小程序二次确认后立即自助执行，保留版本化须知与不可变完成记录，
  移除 V90 申请表、管理端审批菜单和权限（V105）。
- 小程序主包瘦身、支付/订单/购物车/商品详情体验优化；Admin 构建可重复，
  自动导入生成物纳入版本库并由 CI 校验。
